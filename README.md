# Домашка.ПРО 3.3

Школьный помощник для 1–11 классов: решение и проверка заданий по тексту и фото, учебный диалог, калькуляторы, шпаргалки, тренировки, дневник и расписание.

Исходники извлечены из исходного workspace ZIP в корень репозитория. ZIP оставлен как исходный снимок **3.2**; актуальный код находится в `src/`, `backend/` и `shared/`. Готовые HTML/ZIP и `static/` генерируются и не хранятся в Git.

## Новое в 3.3

### Выбор нейросети

Нажмите кнопку настройки ИИ в шапке:

- **Бесплатный облачный ИИ без ключа:** автовыбор, Qwen 3.5 Omni, Pollinations или Qwen 2.5 VL. Это существующие публичные шлюзы, а не гарантированно доступная или локальная модель. Pollinations сам маршрутизирует запрос к модели.
- **OpenRouter:** свой API-ключ, обновляемый список бесплатных моделей и `openrouter/free` для автоматического выбора. Текстовые модели используют отдельное распознавание фото.
- **Gemini:** свой ключ Google AI Studio, конкретная модель или явный автовыбор Flash → Flash-Lite. Доступность бесплатной квоты и возможный биллинг определяются аккаунтом и правилами Google.
- **Ollama / свой API:** OpenAI-совместимый адрес и имя модели.

Конкретная выбранная модель больше **не заменяется незаметно** другой при ошибке. Отсутствующий ключ не переключает приложение на другого провайдера. Только явно выбранный автовыбор допускает резервирование. Проверка связи проверяет реальное облачное соединение, а не локальный запасной ответ.

### Детский режим с родительским паролем

1. Выберите класс ребёнка и настройте нейросеть.
2. Нажмите кнопку со щитом/замком в шапке.
3. Задайте и подтвердите родительский пароль (8–128 символов).
4. Включите режим. Для выхода или смены пароля потребуется действующий пароль.

В этом режиме доступны **репетитор, дневник и справочник**. Обычные чаты скрываются, но не удаляются. Проверки-чистовики, калькуляторы решений, генераторы ИИ-тестов, импорт/экспорт общей истории и изменение настроек ИИ закрыты. Новые учебные диалоги сохраняются отдельно по признаку режима.

Репетитор получает возрастные инструкции: один шаг, короткая подсказка и один вопрос за раз; без готового ответа, сочинения или кода решения. Политика применяется к первому запросу, дальнейшему диалогу, запросам через Python-сервер и локальному запасному ответу. Точное решение/бейдж с корнями не выводится. Контекст длинного диалога ограничен исходным заданием и последними обменами, чтобы уменьшить объём запросов. Фото остаётся доступно в продолжении диалога, если Vision-модель не вернула OCR-текст.

**Границы защиты:** это локальная защита интерфейса и учебная политика, а не полноценный родительский контроль. Новый браузер/профиль, очистка данных, инструменты разработчика или изменение HTML могут обойти её. Состояние сайта не переносится автоматически в скачанный HTML. Нейросеть может нарушить инструкции — гарантировать отсутствие готовых ответов нельзя. Для строгой защиты нужны аккаунты, серверная авторизация и серверная политика, не управляемая клиентом.

Пароль не отправляется в сеть и не хранится открытым текстом: используется PBKDF2-SHA256, случайная соль и 310 000 итераций. Есть задержка после повторных неверных попыток. Настройка требует постоянного хранилища браузера и Web Crypto (HTTPS либо локальный HTML в современном браузере). Восстановления забытого пароля нет.

## Запуск и сборка

Нужны **Node.js 20+** и **Python 3.11+**. Для одного готового HTML они не требуются.

```bash
npm ci
python3 -m venv .venv
# Linux/macOS:
.venv/bin/pip install -r requirements.txt
# Windows: .venv\Scripts\python -m pip install -r requirements.txt

# Собрать сайт и автономные HTML/ZIP:
npm run build:standalone

# Запустить сайт с серверными ИИ/OCR-запросами:
.venv/bin/python server.py
```

Откройте `http://localhost:8000`. На Windows используйте `.venv\Scripts\python server.py`; при необходимости запустите `npm run build`, затем `python build_standalone.py`.

Для разработки в другом терминале:

```bash
npm run dev
```

Vite слушает `0.0.0.0:5173`, относительные `/api/*` проксируются на Python `:8000`. Браузер не обращается к адресу серверного localhost напрямую. Исключение по назначению — явно настроенный пользователем **локальный Ollama** на его собственном устройстве.

Артефакты сборки:

- `static/` — сайт для Python-сервера;
- `Domashka_PRO.html` и `static/Domashka_PRO.html` — один HTML со встроенными JS/CSS/шрифтами KaTeX;
- `Domashka_PRO_Portable.zip` — HTML, инструкция и ярлыки запуска.

Скачанный HTML открывается напрямую через `file://`. Облачный ИИ и часть OCR/PDF-функций требуют интернета. Калькуляторы на JS, справочник, дневник и история работают локально. Режим с локальным ИИ требует отдельно установленной и запущенной модели; распознавание фото может использовать облако.

## Тесты

```bash
npm test
.venv/bin/python -m unittest discover -s tests -p 'test_*.py' -v
npm audit
```

Тесты покрывают пароль и сохранение режима, защиту всех AI-путей, выбор провайдера/модели, сетевые таймауты/отмену, фотографии и историю, очистку HTML, счётчики и математические решатели. Внешние ИИ/OCR-сервисы подменяются: тесты не расходуют квоты и не утверждают, что публичные шлюзы сейчас доступны. Браузерные проверки интерфейса дополнительно выполнены на настольной и мобильной ширине с тестовыми ответами.

## Данные и безопасность

- Текущий интерфейс сохраняет чаты и фото в IndexedDB, настройки/дневник — в localStorage; при ограничениях хранения используется урезанная резервная история. SQLite обслуживает отдельные серверные маршруты и **не синхронизируется автоматически** с браузерной историей.
- API-ключи хранятся в браузере **не зашифрованными** и передаются выбранному провайдеру, а в серверном режиме также вашему серверу. Родительский пароль не является ключом шифрования данных.
- Облачные ИИ/OCR-провайдеры получают текст и фото. Не загружайте личные данные детей и не встраивайте общие секретные ключи в HTML.
- Markdown очищается от опасного HTML; математический Python-парсер ограничен разрешённой грамматикой.
- Python-сервер предназначен для локального/доверенного использования: это не готовая многопользовательская production-система. Для публичного размещения нужны HTTPS, авторизация, квоты, изоляция вычислений и политика обработки данных.
