# Проверки Домашка.ПРО 4.0

Дата локальной проверки: **5 ноября 2026**. Это отчёт о выполненных проверках, не обещание доступности внешних сервисов или аудит безопасности.

## Автоматические проверки

- Чистая установка `npm ci`: 232 пакета, отчёт npm — **0 известных уязвимостей** на момент установки. Это не доказательство отсутствия всех уязвимостей приложения.
- `npm test`: **158 тестов, 11 файлов, все прошли**. В том числе аккаунты/права/отзыв сеансов, отдельные хранилища и поздние записи, наследование ИИ, привязки/сброс паролей, перенос старых данных, оба хранилища семейных работ, переключение детей без дублирования форм, страницы работ и пустой дневник нового аккаунта.
- OpenRouter: ответ после старого 22-секундного лимита, SSE с побайтовым UTF-8/CRLF и heartbeat, JSON/WebView-fallback, прерванный поток, ограничения размера, HTTP-ошибки, лимит токенов, пятиминутный deadline, отмена и отсутствие автоматического второго запроса после серверного сбоя. Ответы сервисов в тестах **подменены**.
- `python -m unittest discover -s tests -p 'test_*.py' -v`: **33 теста, все прошли, без пропусков** после сборки ZIP. Вывод сборки v3.4 размером 1,1 КБ внутри одного теста относится к его временной фикстуре, не к выпуску.
- `npm run check:reference`: **1263 уникальные карточки, 563 новых; 106 пар, минимум 25 в каждой**. Проверены диапазоны всех 1–11 классов, уникальность новых записей и синтаксис **250 новых формул** в KaTeX. Это не полная независимая проверка фактической точности и не сертификация по школьной программе.

## Браузер: собранный HTML

Playwright + Chromium 153, отдельная тестовая база, фиктивные аккаунты и ключ. Внешние запросы **перехвачены или заблокированы**; реальных ключей и платных генераций не использовалось.

Пройден сквозной сценарий:

1. Создать родителя через форму/вопрос, затем детей 9 и 2 классов с отдельными паролями/аватарами.
2. Настроить родительский OpenRouter и явно передать настройки одному ребёнку. Проверить класс, режим репетитора и запрет самостоятельной смены класса.
3. Назначить разные работы двум детям; чужие задания не показываются.
4. Отправить текст и реальный растровый файл фото; родитель открывает фото по запросу, ставит оценку/комментарий, возвращает работу на доработку, затем принимает исправление.
5. Выгрузить текущую страницу работ: ответ, фото и отзыв присутствуют в JSON. Семейная оценка не подменяет школьные отметки.
6. Ввести оценку одному ребёнку; у другого отметки отсутствуют. Изменить все восемь перемен и вернуть число уроков 9 → 7 → 9 без потери скрытого значения.
7. Задержать подменённый ответ ИИ: галочка получения/сохранения не появляется раньше ответа. У второго ребёнка нет чатов первого.
8. Во время следующего запроса отключить ИИ из родительской вкладки: запрос отменяется, ребёнок выходит из сеанса. После повторного входа новые ИИ-запросы блокируются. Непосредственная проверка отдельной IndexedDB подтверждает: поздний ответ не записан, у первого ребёнка один завершённый чат, у второго — ноль.
9. Проверить «Мой 9 класс»/«Мой 2 класс», выход/повторный вход, отсутствие горизонтального переполнения семейных экранов при 390 и 320 пикселях. Необработанных ошибок страницы нет.

Проверка обнаружила и помогла исправить повторяющиеся React-ключи у двух соседних семейных компонентов и демонстрационные отметки в новом аккаунте. Добавлены регрессионные тесты.

## Локальный файл и эмуляция телефона

Отдельный Chromium-контекст открыл **`file://…/Domashka_PRO.html`**, без сервера и внешних ресурсов. В офлайн-режиме выполнены регистрация родителя, выход, закрытие/повторное открытие файла и вход с тем же паролем. При подменённом User-Agent iPhone HTML Viewer прямого `input[capture]` нет, показывается инструкция выбора готового фото. Проверена ширина 390 пикселей.

**Это Chromium с эмуляцией размеров/UA, не физический iPhone, не WebKit и не проверка конкретного HTML Viewer.** Наличие Web Crypto/хранилища, работа галереи и диктовки на реальном устройстве требуют отдельной проверки.

## Поставка

- `npm run build:standalone` успешно создаёт HTML 4.0, `USER_GUIDE.txt` и ZIP с полной/краткой TXT-инструкциями.
- HTML самодостаточен: JavaScript, CSS и KaTeX-шрифты встроены; внешних ресурсов для загрузки оболочки нет.
- HTML в архиве совпадает с корневым; полная TXT-инструкция совпадает с MD и корневым TXT.
- Повторная сборка после чистой установки даёт **побайтово тот же HTML и содержимое каждого файла архива**. Временные метки контейнера ZIP не нормализуются, поэтому хеш всего ZIP не объявляется постоянным.
- Есть предупреждение Vite о размере монолитного JS. Для переносимого однофайлового запуска код намеренно не разбит на загружаемые внешние чанки.
- GitHub Pages не включались и не публиковались. Новый PR не сливается автоматически.

## Не проверено и не обещается

Живая доступность бесплатных шлюзов/моделей, реальный биллинг и задержки OpenRouter, реальные мобильные камера/микрофон, физические iPhone/Android и работа всех HTML Viewer. Нет межустройственной синхронизации семьи, серверной аутентификации, шифрования всех локальных материалов или полного переносимого бэкапа аккаунтов. Вопрос √49 не подтверждает совершеннолетие. Полного независимого аудита безопасности и экспертизы всех учебных текстов не проводилось.
