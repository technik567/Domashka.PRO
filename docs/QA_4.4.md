## Поставка и воспроизводимость

`Domashka_PRO.html` — автономный файл без облачных ключей; WebP и шрифты внутри. `Domashka_PRO_Portable.zip` — **15 файлов** под `Domashka_PRO/`, включая полное руководство и команды запуска. `Domashka_PRO_Cloudflare.zip` — **14 файлов** с `index.html` в корне, неизменёнными публичными Supabase/Site key и отдельным локальным HTML. Никаких SQL, Edge secrets или служебных файлов в ZIP.

Две полные сборки подряд сравниваются по SHA-256: HTML, TXT и оба ZIP побайтно одинаковы. ZIP-время/permissions фиксированы, тесты сверяют содержимое пакетов с текущими исходниками и руководством. Сборка не загружает файлы в Cloudflare и не развёртывает Supabase.

## Отдельная добровольная сетевая проверка

Обычные unit/CI/browser тесты **не отправляют** живые запросы провайдерам. В существующем workflow `check.yml` добавлен отдельный `public_smoke=false` по умолчанию. Только явный запуск с `true` разрешает `scripts/probe_public_routes.mjs`: короткое вымышленное `2 + 2`, официальный Qwen3 adapter и один keyless-запрос Tavily. Никаких ключей/secrets, реальных заданий или платных сервисов; при отказе общей площадки остальные модели не перебираются. Общий предел job 8 минут, отчёт `public-route-smoke` отдельно от локальной регрессии. Даже успешный Node-запрос не доказывает browser CORS/доступ с телефона. Наличие такого скрипта само по себе не является успешным live-тестом.

### Полученный живой результат

Запущен [отдельный сетевой прогон 44562538889](https://github.com/technik567/Domashka.PRO/actions/runs/44562538889), не локальные моки:

- **Tavily keyless — HTTP 200, реальный результат:** `https://science.nasa.gov/solar-system/solar-system-facts`, на безличный запрос `NASA solar system planets`. Не использовались API-ключ, аккаунт пользователя или платный fallback. Это подтверждает один серверный Node-запрос; **не** CORS/HTML Viewer, оставшуюся квоту и не действующий облачный `web-search`.
- **Qwen3 8B — не подтверждён:** адаптер завершился с `errorCode: upstream` за 300 мс, без принятого текстового ответа. Остальные четыре варианта той же площадки не запускались после отказа, без перебора для обхода ограничений. Причину на стороне площадки из одного безопасного кода не устанавливаем. Все пять остаются экспериментальными; **0 новых моделей с подтверждённым живым ответом**.
- Сетевая job поэтому **FAIL**, обычная test/build job — **PASS**. Отказ внешнего демо не замаскирован «зелёными» unit-тестами.
- Артефакты/логи Actions загружаются через хосты, недоступные из sandbox. Существующий отчёт прочитан [report-only job](https://github.com/technik567/Domashka.PRO/actions/runs/44563077078/job/135697365633) и опубликован как annotation, **без повторных запросов провайдерам**. Поле `public_report_run` запускает только такое чтение; `public_smoke` при этом выключен.
