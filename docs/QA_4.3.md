### Что именно проверяется

- Math interpreter: приоритет `-x²`, правая ассоциативность степеней, `2^-2`, неявное умножение, функции, полюса и недействительные значения, ограничения размера/глубины/токенов. Нет eval/Function; запрещены свойства, присваивания и JS-код.
- Графики: schema/числовые границы/порядок точек, 4-chart cap, экранирование подписей, SVG/таблицы/KaTeX, отсутствие загрузки model HTML/images. Реально скачан SVG, создан print PDF. Вид проверен на 320 px; физический iPhone не проверялся.
- Рассуждение: тела Gemini budget 512/2048/8192 и OpenRouter effort, непоказ thought parts, неизвестная/null capability = инструкция, proxy parity и запрет готового ответа/поиска в tutor.
- Search handler исполняется из настоящего TypeScript с подставными Auth/RPC/Tavily: порядок проверок, разрешённый Origin, отсутствие ключа, отказ Auth, неподходящий session, owner-secret не в ответе, разрешённые поля/размеры, ровно один basic call, bounded response и безопасные URLs.
- SQL: service-only RPC, отсутствие доступа anon/authenticated к квоте, настоящие actor/session/confirmation/disabled/revoke/epoch, tutor/AI policy, идемпотентность, 8/hour, 30/day, 900/month. Поисковые фразы и ключи не входят в ledger.
- Помощник: add_text → predict с отдельным криптографическим session_hash, отсутствие cookies/ключей, никаких обходов 401/403/429, bounded complete-SSE, отдельная история без основного задания, редактирование распространённых секретов, site-only ограничения. Локальная справка не называется ИИ, сетевой вызов только по кнопке, история очищается, model links не активны.
- Тур: реальные подсвеченные элементы, переход по кнопкам, пропуск/Escape/повтор, память выбора, отдельный auth intro, адаптация при запрете AI. Ничего автоматически не отправляется в модель.
- Ранее существующие семейные/роль/карточки/калькуляторы/OCR/квоты/таймер/перенос/Word-экспортные тесты сохранены.

## Воспроизведение

```sh
npm ci
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
npm test
npm run check:reference
npm run test:cloud
npm run build:standalone
.venv/bin/python -m unittest discover -s tests -p 'test_*.py' -v
deno check --no-config --node-modules-dir=none --frozen --lock=supabase/functions/deno.lock supabase/functions/family-admin/index.ts supabase/functions/web-search/index.ts
```

Опциональный Chromium: установить `playwright-core` в `.cache/browser`, указать `CHROMIUM_PATH` и при необходимости `PLAYWRIGHT_MODULE`. `node scripts/test_cloud_browser.mjs` создаёт fixture-сайт; затем `node scripts/test_features_browser.mjs` проверяет CSP, графики и помощь. В песочнице использованы @sparticuz/chromium 153 и библиотеки его AL2023 archive, `LD_LIBRARY_PATH="$PWD/.cache/chromium-libs/lib"`. Снимки, PDF и логи в `.cache/`, не в Git. Это не сетевые проверки внешних провайдеров.

Облачный ZIP: `DOMASHKA_SITE_URL=auto` плюс публичные проектные URL/key, `python3 scripts/prepare_cloud.py --zip Domashka_PRO_Cloudflare.zip`. `_headers` и `index.html` в корне. Исходный отслеживаемый HTML и его копия для скачивания не получают облачную конфигурацию. Архивируются только разрешённые публичные файлы, не произвольное содержимое output-каталога.
