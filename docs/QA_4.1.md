## Что проверяют новые автоматические тесты

### Каталог, маршрутизация и защита

- Пять различных ID, хостов и моделей; три Google Gemma, Meta Llama и Mistral. Всего 9 пунктов с учётом автовыбора.
- Один JSON-каталог для JS/Python: точный endpoint, схема параметров, возможности фото, описания/оценки и источники.
- Каждый явный выбор обращается только к своей площадке. Неизвестный/внедрённый ID задания не превращается в URL.
- Нет Authorization/cookies внешнего аккаунта, ключи других провайдеров не отправляются, редиректы запрещены. Python не использует прокси окружения и не пересылает cookies из предыдущего ответа.
- Нет подмены модели или повтора после HTTP 401/403/429/503; ошибка Python-моста не вызывает дублирующий прямой запрос.
- Локальная история передаётся явно; новая сессия Gradio на каждый запрос. Системные правила репетитора не теряются в мультимодальной или текстовой схеме; принудительный репетитор использует уменьшенный бюджет 384 токена.
- Слишком длинное условие отклоняется до загрузки фото/сети, не обрезается незаметно.

### Фото и поток

- Обе визуальные Gemma загружают реальное содержимое фото через multipart и передают FileData по полученному пути; не запускают OCR в строгом Vision.
- Текстовые модели и лишние фото отклоняют строгий Vision до сети. При явном OCR передаётся текст, не исходное изображение.
- UTF-8 и CRLF на границах фрагментов, BOM, heartbeat, промежуточные полные версии, `complete` без завершающей пустой строки, WebView без потокового reader.
- Ошибки внутри HTTP 200, `error:null`, пустой/неожиданный ответ, HTML входа, повреждённый JSON, обрыв и слишком большое событие не сохраняются как ответ модели.
- Сырой текст ошибки с условным секретом/приватным заданием не попадает в сообщение пользователю.
- Один пяти­минутный бюджет распространяется на молчащее тело постановки в очередь и ответ. Проверены отмена и WebView без `AbortSignal.reason`.
- Python: `asyncio.wait_for` отменяет ожидание и при молчащем теле submit, и при молчащем SSE — не только при отсутствии HTTP-заголовков.

### Интерфейс

- Все новые варианты сохраняются и восстанавливаются, показывают возможности/источник/цветные оценки и предупреждение об общей квоте.
- Встроенный селектор не появляется у Gemini/OpenRouter/своего API. Сохранённые настройки других провайдеров не заменяются.
- Нет фоновых запросов к новым демо при открытии селектора. Без callback смены (управляемый профиль) выбор read-only.
- Прежние наборы тестов семьи, парольных ограничений, локальных хранилищ, фото, OpenRouter, расписания и справочника также проходят.

## Браузер: собранный HTML, не исходники

**Chromium + Playwright**, отдельно установленные в игнорируемую `.cache/browser`; Linux-бинарник `@sparticuz/chromium`. Итоговый сценарий запущен с обычной CORS-защитой, **без `--disable-web-security`**. Первый технический запуск с рекомендуемыми Lambda-флагами single-process завершил браузер при смене контекста; после перехода на обычные отдельные процессы сценарий полностью повторён.

Итог: **12 проверок, 19 подставных запросов, `pageErrors=[]`, неожиданных внешних запросов нет**. Повторный прогон финального HTML — PASS, 60,9 с при параллельной работе полного набора тестов.

1. На локальном HTTP-сайте открыт готовый HTML с `__STANDALONE_BUILD__=true`.
2. Для всех пяти моделей: выбор в чате → перезагрузка → сохранённый выбор → настройки → «Проверить соединение» → ответ именно соответствующего подставного маршрута. Поля ключа не появляются.
3. Настоящий небольшой PNG с треугольником обработан приложением в JPEG, отправлен multipart в подставное демо Gemma 3n, FileData дошёл в запрос генерации. Три запроса (upload/submit/SSE), без OCR и чужих шлюзов.
4. Квота возвращена как SSE error при HTTP 200: показана ошибка, нет повтора или успешного локального ответа.
5. Проверка соединения остановлена во время задержки; поздний подставной ответ не заменил сообщение «Проверка отменена».
6. `file://` с **симулированным iPhone HTML Viewer UA**, 390 и 320 px: модель сохраняется после закрытия/повторного открытия страницы, горизонтального переполнения нет, input с `capture` отсутствует.
7. Из локального файла выполнен запрос с null-origin к подставному cross-origin endpoint с явно разрешающими CORS-заголовками.

Это проверяет приложение и формат запросов, **не качество ответа модели, живой CORS Hugging Face или работу физического iPhone/WebKit**. Ответ про треугольник был задан тестовым транспортом — он не доказывает распознавание изображения моделью.
