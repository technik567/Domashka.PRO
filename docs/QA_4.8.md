# Проверки 4.8 — независимый поиск до первой генерации

## Архитектура и границы

- По явному выбору владельца поиск теперь решается **локальными правилами приложения**, а не ИИ: текстовая тема → настоящий поиск → первая генерация выбранной модели → проверки. Простая математика/объяснения обычно пропускают поиск. Правила — эвристика, не понимание задачи; возможны пропуски и ложные отказы.
- Нет отдельного поля «что искать». Берётся только текущий введённый вопрос; для checker — условие/тема, не ученический черновик. История, предыдущие ответы, фото/OCR, профиль и внутренние шаблоны не являются входом поиска. Неясные/длинные/структурные/похожие на личные данные формулировки останавливаются до сети; не обрезаются/не дополняются из истории. Фильтр не является полной анонимизацией, не вводить личные данные.
- До одного запроса, 3–180 символов / 12 значимых слов; исходная поисковая инструкция ≤2000 символов. Проверяется весь ограниченный вход до удаления слов. На всех глубинах одинаковый поисковый бюджет; с поиском и без — 1/2/3 генерации для off-low/medium/high.
- После успешного поиска даже отказ **первой** генерации оставляет реальные инертные выдержки/URL, явно **не готовое решение и не ответ выбранной модели**. Нет фиктивного предыдущего успешного ответа, ложного Vision/OCR-бейджа, проверки/повтора/скрытой замены выбранного канала. Такие выдержки не начисляют solve/check/XP и не записываются в ошибки ученика.
- Если поиск не удался, модель не вызывается. Если поиск пропущен и модель отказала, сохраняется ошибка, не локальная подмена. Модельные JSON/actions и native tools не запускают рекурсивный поиск. Stop, смена аккаунта/политики отменяют следующие шаги и поздний sources-only.
- Teacher/tutor, реальная глубина и проверки, графики, фото/Vision/OCR, ручной выбор и Auto сохранены. Tavily keyless/необязательный ключ, серверные Auth/квоты остаются прежними. Внешние квоты/недоступность Qwen/Gemma/Pollinations не объявлены устранёнными.

Внешний HTTP Auth/Storage/AI/search в локальных проверках подставной; PGlite исполняет реальные SQL. Это не живая авторизация, генерация, доступность поиска или физический iPhone. Исторические проверки 4.7 не переименовываются в проверки 4.8.

Покрытие новой архитектуры:

- Локальные positive/negative-правила, явные источники/актуальность, математика и объяснения без поиска, пользовательское «без интернета», границы входа/фразы, имена/контакты/секреты в конце входа до удаления слов, Unicode, код/URL/обёртки. Неизвестная тема не дополняется из истории.
- Настоящие API-boundaries: задача, checker condition без draft, пустая тема при photo-only, follow-up question без шаблонов/предыдущих реплик. Контекст модели и фото сохранён отдельно от поискового ввода.
- Поиск раньше **любого** model request; 1/2/3 генерации на разных глубинах; проверенные источники передаются уже первой генерации. Ошибка поиска/пустые/невалидные результаты — ноль генераций. Без поиска ошибка модели не превращается в фиктивные источники или запасной локальный ответ.
- Отказ первой Pollinations/Qwen-генерации с реальными клиентскими адаптерами и fixture HTTP: только выдержки, `calls:1/searches:1/verified:0`, без prior-success metadata/старого OCR/приписанной Vision-обработки, повторов и скрытой замены выбранного канала. Сохранение истории и фото не начисляет XP/solve/check и не захватывает ошибки ученика.
- Model actions, malformed/legacy controls, native tools и review-команды не запускают второй поиск/repair. Ошибки, private reasoning, tool arguments и provider body не появляются в receipt.
- Hosted fixtures: Auth-запрос остаётся через web-search, без прямого обхода квот/политики. Смена аккаунта, tutor или allow-AI во время поиска и первой генерации прерывает ожидание; поздние ответы не публикуют sources-only. Stop, включая немедленную отмену из status callback, блокирует последующие шаги.
- Собранный HTML, светлый/тёмный 320/390 px: поиск первым, работа обычного ответа/review, стадии 503/квот/обрыва, локальный отказ неоднозначной/личной темы до сети, source-only с инертными Markdown/HTML/GFM URL, реально доступная при прокрутке ссылка не заблокирована sticky composer. Ручной Qwen не заменяется; его ошибка больше не мешает уже полученным источникам. Черновики/фото/история/настройки/10 кодов сохранены.
- Probes: один search → один model, нет запросов без флага, нет ключей/Auth/HF/повторов; факт только в заголовке источника не выдаётся за ответ модели. Sources-only отдельно от verified AI answer.

Первый Python-прогон обнаружил ещё не пересобранный Cloudflare ZIP (отсутствовал новый QA-файл); после сборки пакета оба distribution-теста и все 89 тестов прошли. Подготовка Chromium потребовала штатной распаковки `al2023` libraries и `LD_LIBRARY_PATH`, не ослабления CSP. Пробные HTTP не отправлялись внешним сервисам.
