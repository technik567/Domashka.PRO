# Публичные демо без ключей — 4.1

**Дата проверки документов, исходников и GET API: 2026-11-06.**

Добавлены пять отдельных моделей/Space, а не пять названий одного роутера. Ключи и внешняя регистрация не нужны **в пределах доступного анонимного режима площадки**. Бесплатность не означает безлимит, гарантию доступности или дополнительные независимые квоты.

**Важно о проверке:** живой запрос генерации, загрузка фото, браузерный CORS и фактическая выдача анонимной GPU-квоты **не проверены**. Среда разработки разрешает исходящие соединения только с ограниченным набором хостов; доступный веб-инструмент читает публичные GET-страницы, но не выполняет POST генерации. Успешный `/info` не доказывает успешный ответ модели. Поставка содержит адаптеры по опубликованным контрактам и тесты с подставным транспортом; пользователь может проверить свой текущий доступ кнопкой **«Проверить соединение»**. Это настоящий запрос, расходующий квоту, а не фоновый опрос.

Gemma — семейство моделей **Google**, не Gemini API. Демо обслуживаются Hugging Face / владельцами Spaces, не платным API Google. Mistral запускается в демо **hysts**, не в официальном API Mistral. Llama 3.2 3B — маленькая текстовая модель; русский и сложная математика требуют особенно внимательной проверки. Кружки — редакционные ориентиры, **не измерения качества/скорости** этих сервисов.

У всех пяти Space на дату проверки метаданные сообщили `RUNNING`, `gated:false`, `private:false`, а `/gradio_api/info` — публичную функцию. Идентичность проверялась также по `MODEL_ID` и загрузке модели в `app.py`: список `models` в метаданных может содержать и ссылки из описания (например, Gemma 2 27B), это не дополнительный доступный маршрут.

Единый каталог `shared/public-demos.json` используется JavaScript и Python. Он содержит точные хосты, ID, схемы, ограничения, дату проверки контрактов и ревизии исходников. Это **не автоматическая проверка загруженных весов** и не обещание, что владелец Space никогда не сменит модель.

## Анонимный доступ и квота

В [документации ZeroGPU](https://huggingface.co/docs/hub/spaces-zerogpu#usage-tiers) на дату проверки для **Unauthenticated** указаны **2 минуты GPU в сутки, низкий приоритет очереди**, восстановление включённой квоты через 24 часа после первого использования. Это GPU-время, а не две минуты настенного ожидания или фиксированное число ответов. Правила площадки могут измениться.

- Квота общая для ZeroGPU-демо, а не отдельные две минуты для каждого пункта списка. Другой профиль приложения или другая модель **не должны использоваться для обхода лимита**.
- Демо запрашивает резерв длительности заранее. Gemma 3/3n запрашивают **120 с**, Gemma 2 и Llama — **90 с**, Mistral — **60 с**. При остатке меньше резерва может быть отклонён даже короткий запрос. Для Gemma 3/3n это может означать только один запуск до восстановления квоты.
- Мы не меняем заявленную длительность на стороне сервиса, не подделываем IP, не создаём аккаунты и не встраиваем чужие ключи.
- Авторизация/оплата не запускаются автоматически. Если анонимный доступ запрещён, приложение покажет ошибку. Указание ключа от другого провайдера не делает этот маршрут авторизованным.
- В Python-режиме у разных посетителей сервера может оказаться общая сетевая квота. Остановка ожидания в браузере не гарантирует остановку работы удалённого сервера или возврат GPU-времени.
- Прежний «Автовыбор» по-прежнему использует Qwen/Pollinations и явно обозначенные локальные инструменты. Новые демо выбираются **вручную**, не участвуют в гонке запросов и не тратят квоту в фоне.

### Что не добавлено

- Собственный ключ Gemini/OpenRouter не соответствует запросу «без ключей и регистрации». Эти существующие провайдеры остались отдельно в настройках.
- Не созданы псевдонимы Google/Llama на Pollinations. [Текущая Classic-документация](https://github.com/pollinations/pollinations/blob/master/APIDOCS.md) описывает ограниченный анонимный маршрут, а не произвольный каталог Google без ключа.
- Gemma 4 31B/26B Space имеют публичный API, но найденный [исходник 31B](https://huggingface.co/spaces/huggingface-projects/gemma-4-31b-it/blob/a4709af0ee0ad4d6532e989404810e1876afb971/app.py) запрашивает **180 с** GPU — больше документированной анонимной квоты 120 с. В безключевой список они не включены. Их старые записи OpenRouter не переименованы в безключевые.
- Остановленные/ошибочные демо (например, найденное Llama 3.2 Vision 11B) и исчезнувшее AMD Gemma 27B не включены.
- WebGPU-демо с загрузкой больших весов на устройство не выдаются за бесплатное облако.

## Контракты транспорта

Опубликованные спецификации, проверенные GET:

- [Gemma 3 12B API](https://huggingface-projects-gemma-3-12b-it.hf.space/gradio_api/info)
- [Gemma 3n E4B API](https://huggingface-projects-gemma-3n-e4b-it.hf.space/gradio_api/info)
- [Gemma 2 9B API](https://huggingface-projects-gemma-2-9b-it.hf.space/gradio_api/info)
- [Llama 3.2 3B API](https://huggingface-projects-llama-3-2-3b-instruct.hf.space/gradio_api/info)
- [Mistral 7B API](https://hysts-mistral-7b.hf.space/gradio_api/info)

Вызов: `POST {host}/gradio_api/call/{apiName}` с JSON `{data:[...],session_hash:"новый-на-каждый-запрос"}`. Затем `GET .../{event_id}` с SSE. Используется совместимый позиционный API, а не необязательный `/call/v2`.

**Gemma 3/3n:** `[{text,files}, system_prompt, max_new_tokens]`.

**Gemma 2/Llama/Mistral:** `[message, max_new_tokens, 0.6, 0.9, 50, 1.2]` — температура, top-p, top-k, repetition penalty. У публичной функции нет отдельного `system_prompt`: правила учителя включаются в начало сообщения. Для всех моделей сохраняются правила репетитора. Инструкции для LLM не являются гарантией отсутствия спойлеров.

История Gradio скрыта из публичных параметров. Поэтому передаётся текст текущего локального диалога; на каждом запросе создаётся новая сессия Space. Нет общей удалённой истории для разных учеников. В репетиторе действует существующее ограничение истории, а слишком большой итоговый текст отклоняется до сети, без скрытой обрезки исходного условия. Лимит символов — предварительный барьер, **не точный подсчёт токенов**: провайдер может отказать раньше (у текстовых демо контекст 4096 токенов, у Gemma 3n в исходнике 10 000).

Фото: `POST /gradio_api/upload`, multipart-поле `files`; возвращённый абсолютный путь той же площадки передаётся как `FileData` с `meta._type="gradio.FileData"`. Только одна фотография JPG/PNG/WebP. URL пользователя не загружается сервером как фото. Веса модели не скачиваются. Текстовые модели не получают изображение под видом Vision; в OCR им уходит распознанный текст. OCR может обращаться к другим внешним сервисам по существующим правилам приложения.

События `heartbeat` не обозначают ответ. `generating` содержит полные промежуточные версии, **не дельты**. Успехом считается только непустая строка первого выхода события `complete`. `error`, даже при HTTP 200, обрыв, HTML-страница входа, неподдерживаемая структура и пустой результат — ошибки. Если Gradio скрывает подробности (`error: null`), показывается общее сообщение, а не выдуманная причина.

## Ограничения и безопасность реализации

- Фиксированные HTTPS-хосты; ID события проверяется перед построением URL. Нет произвольного адреса в имени модели.
- Браузер: `credentials:omit`, запрет редиректов, `no-referrer`. Нет Authorization или передачи ключей других провайдеров. Python использует новый HTTP-клиент без переноса пользовательских cookies/прокси окружения, без редиректов, очищает cookies между запросами.
- Один общий лимит **300 секунд** на фото/постановку в очередь/тело ответа. Python применяет `asyncio.wait_for` ко всей операции, а не только тайм-аут чтения одного пакета. Браузерный Python-мост ждёт 315 секунд; ошибка сервера **не дублируется** прямым запросом.
- Не более **8 млн символов потока** и **100 тыс. символов события**. Gradio повторяет полный ответ в каждом обновлении, поэтому общий лимит больше, чем для токен-дельт OpenRouter. Промежуточные версии не добавляются к итоговому ответу и не сохраняются в истории.
- До **1536 новых токенов**, в репетиторе **384**. Провайдер может дать меньше из-за контекста. API не сообщает причину остановки по лимиту: длинный ответ может потребовать ручного продолжения.
- Ошибки классифицируются, но сырые ответы провайдера с путями/фрагментами задания не выводятся в диагностику. Автоматических повторов, обхода квот, оплаты и незаметной смены модели нет.
- Отмена/отзыв сеанса обрывают ожидание на клиенте. Запоздалый результат не записывается в другую локальную тетрадь. Это не гарантия удалённой отмены GPU-задачи.
- Текст, история текущего диалога и выбранное фото уходят владельцу публичного демо. Не отправляйте личные данные. Локальные аккаунты/пароли не становятся аккаунтами Hugging Face.

## Ручная проверка вне ограниченной среды разработки

1. Открыть собранный HTML или сайт, оставить провайдер «Бесплатный облачный ИИ».
2. В чате выбрать конкретное демо; убедиться в подписи модели, карточке и предупреждении об общей квоте.
3. Открыть настройки → **«Проверить соединение»** один раз **либо сразу отправить рабочее задание вместо отдельной проверки**. Не проверять все пять подряд: это общая квота. После проверки для Gemma 3/3n может не остаться полного резерва на фото; шаг 4 выполнять вместо проверки или после восстановления квоты. Успешное чтение каталога не считается генерацией.
4. Для Gemma 3/3n выбрать «Само фото (Vision)» и передать один безличный рисунок. Проверить подпись Vision и упоминание модели в ответе; сам факт передачи не доказывает правильного понимания рисунка.
5. Для текстовой модели проверить отказ строгого Vision и отдельно явный OCR.
6. При очереди нажать «Остановить»; после отмены не должно появиться позднего ответа в чате. Не повторять запрос автоматически.
7. При отказе в анонимном доступе/квоте остановиться и дождаться восстановления. Не регистрироваться, не менять IP и не подставлять ключ для обхода ограничения.
8. Повторить сценарий на **физическом iPhone/HTML Viewer** отдельно: CORS, отсутствие потокового чтения и правила WebView могут отличаться от Chromium. HTTPS в Safari предпочтительнее, но не гарантирует доступность демо.
