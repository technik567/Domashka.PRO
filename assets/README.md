# Study workspace background

`study-background.webp` is an AI-generated decorative photograph created for this project in Arena. No people, text, external URLs or user photos. Converted to WebP (1376×768, 12 KB) and embedded in the standalone HTML via Vite `?inline`; no additional network request. Users can disable it in Settings. Text is rendered on opaque surfaces; a dark overlay is used for dark mode. Original full-size generation is not shipped.
